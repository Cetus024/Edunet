# EduNets overview

EduNets is a study platform for Singapore O-Level students and teachers. It provides quizzes, concept maps, note capture, memory tracking, collaborative study tools, and performance support.

## Personas

- **Student** — Learners preparing for Singapore O-Level exams who use the platform for revision and study management.
- **Teacher** — Educators or content creators who manage study materials and quizzes.

## User stories

- As a Student, I want to access a personalised dashboard so that I can quickly see my study progress and upcoming tasks.
- As a Student, I want to take smart quizzes so that I can practise and improve on weaker topics.
- As a Student, I want to view concept webs so that I can understand topic relationships visually.
- As a Student, I want to capture notes or questions so that I can store ideas and clarify doubts later.
- As a Student, I want to update my profile so that I can keep my study preferences and personal info accurate.
- As a Student, I want to track quiz history so that I can understand my performance trends.
- As a Student, I want to receive study recommendations so that I can focus on areas needing improvement.
- As a Student, I want to join a friend's Rescue room with my name and initials avatar so that we can start a shared live quiz together.
- As a Teacher, I want to upload or update quiz questions so that students always access accurate content.
- As a Teacher, I want to publish concept web diagrams so that students can understand key connections.
- As a Teacher, I want to review student performance insights so that I can refine study resources.
- As a Teacher, I want to manage study materials so that students receive updated content.

## App scopes

- **EduNets** (Power Apps code app) — Used by students to access quizzes, concept webs, captured notes, and personalised study tools.
- **Teacher content assistant** (Copilot Studio agent) — Helps teachers upload quizzes, publish concept webs, and manage study materials.
- **Performance insight alert** (Copilot Studio flow) — Notifies teachers when new quiz history is recorded to support performance review.
